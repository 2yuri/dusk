## Dusk 1.0.0

Dark mode for every website, built so the page you're reading doesn't pay for it.

### Install

1. Download **`dusk-1.0.0.zip`** below and unzip it.
2. Open `chrome://extensions` and turn on **Developer mode** (top right).
3. Click **Load unpacked** and pick the unzipped folder.

Chrome 120 or newer. To verify the download: `shasum -a 256 dusk-1.0.0.zip` should match `dusk-1.0.0.zip.sha256`.

### What only Dusk does

- **It uses the site's own dark theme, even behind a toggle.** Dusk finds the hook in the site's CSS (`.dark`, `data-theme="dark"`, `data-bs-theme`...), sets it, and checks that the page really went dark. In a survey of 30 popular sites, Dusk used the site's own theme on 19 of them instead of approximating one.
- **It shows what it costs.** The popup reports how much main-thread time Dusk's own work took on the page.
- **It checks that text is readable.** Visible text is measured against what's really painted behind it, and anything below WCAG AA is lightened.
- **"Fix a spot."** Click a logo that vanished or an image that glares, choose Invert or Dim, and the fix is saved for that site. Fixes can be copied in Dark Reader's config format.

### Everything else

- Dynamic mode (rewrites colors, including CSS variables, Tailwind, shadow DOM and CSS-in-JS), Filter mode, and per-site Auto / Dynamic / Filter / Off.
- Uses `prefers-color-scheme` dark themes when a site ships one, and leaves sites that are already dark alone.
- Dark icons drawn as CSS backgrounds are recolored. The analysis runs in the background worker, never on the page.
- Brightness, contrast, sepia, grayscale, and custom background and text colors, with a live preview.
- Schedule: always, follow the system, or a time range. Allow-list mode.
- Dark Reader's community site fixes (about 2,900 sites, MIT).
- A settings page with per-site modes, your fixes, export/import and cache control.
- Shortcuts: <kbd>Alt+Shift+D</kbd> everywhere, <kbd>Alt+Shift+A</kbd> this site.

### Size and speed

- **44 KB** of script per page (15 KB gzipped), vs about 390 KB for Dark Reader. The picker (9 KB) loads only when used.
- Main-thread time spent by the extension, median of 5 interleaved cold loads (Chrome 155):

| Site | Dusk | Dark Reader |
|---|---|---|
| Reddit | **93 ms** | 491 ms |
| GitHub | **70 ms** | 284 ms |
| BBC News | **56 ms** | 85 ms |
| Wikipedia | **34 ms** | 83 ms |
| MDN | **25 ms** | 31 ms (doesn't darken MDN) |
| Hacker News | **10 ms** | 26 ms |
| Python docs | 11 ms | 11 ms |

### Privacy

No analytics, no telemetry, no servers. Dusk only requests stylesheets and images the current page already uses, without cookies. Nothing is cached in Incognito. See [PRIVACY.md](https://github.com/2yuri/dusk/blob/main/PRIVACY.md).
